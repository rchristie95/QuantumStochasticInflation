# Retired tooling

`retired-tools/` preserves the old section-assembly builder and its tests,
installation demo, standalone preview launcher, duplicate short physics check,
and the README for the previous folder layout.

Executable files have an extra `.txt` suffix so they cannot be accidentally
launched or collected as active tests. They are historical references only.
Current build commands are in `../README.md`; active checks are in `../../tests/`.
